**海水养殖实时监测预警与智能管理系统 | 项目负责人 第三届全国智慧海洋大数据与人工智能应用创新大赛(2024) 获奖项目**

- 针对海水养殖"人工经验依赖、异常发现滞后、资源粗放投喂"痛点，设计**"多源感知-数据融合-智能预测-预警决策"一体化系统**：接入水质传感器、水下摄像头、声呐、气象站、浮标与卫星遥感等多源设备数据，经清洗质控与标准化后统一入库，实现养殖环境全方位实时感知；
- 构建**LSTM-BP组合水质预测模型**（Keras/TensorFlow）：针对单一LSTM收敛慢、精度不足问题，将LSTM隐层输出接入BP网络做二次误差修正，通过反向传播联合优化权重偏置，实现水温/pH/溶解氧等多参数未来一周滚动预测与超限自动预警；
- 集成**基于计算机视觉的鱼类行为目标检测**（OpenCV视频流处理+深度学习检测模型），识别鱼类进食、活动及异常死亡事件，结合随机森林/SVM健康评估模型输出鱼类健康风险报告；
- 系统采用Django+MySQL+WebSocket架构实现监测数据实时推送与可视化看板（7类统计视图），已在**大连海洋大学水产养殖学实验教学示范中心完成整套软硬件部署**，并在海洋养殖环境信息综合应用服务平台验证运行。
